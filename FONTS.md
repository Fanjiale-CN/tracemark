# TraceMark — Font Licenses

TraceMark bundles four fonts under their original licenses. Keep this file when redistributing.

**Primary zhuan typeface: `chongxi_seal.otf` (崇羲篆體, Chong Xi Small Seal)** — a true xiaozhuan (小篆) canon typeface derived from《說文解字》(11,596 characters). It drives the zh track; the bundled 峄山碑篆体 remains as a fallback reference. Because the Chong Xi license is CC BY-**ND** (NoDerivatives), the font must be redistributed as-is — never subsetted or converted.
