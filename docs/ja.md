# TraceMark 痕跡追溯（日本語）

写真＋一行テーマから、装飾的なスタンプはがきの PNG を生成するスキルです。
Trace every mark.

## ルーティング表（先に AUP.md を読み、可用性を確認する）

| 軌道 | トリガー | テンプレート |
| --- | --- | --- |
| zh（中国篆刻） | 中国語の氏名/齋館名/吉語/都市記念 | render.py 内蔵（朱文方印/白文方印/円形閑章） |
| jp（日本のはがき印） | カタカナ/日本の文具テイスト/駅スタンプ風 | render.py 内蔵（丸型墨にじみスタンプ） |
| wz（西洋ワックスシール） | モノグラム/結婚式/ギフト/ブランド封筒 | render.py 内蔵（ワックスシール円形印影） |

**カテゴリの可用性**：印章モードでは企業・機関・政府の名前は使えません（validate_input.py が拒否し、切手スタイルへ優しく誘導します）；切手・はがきスタイルでは機関名も使えます。AUP.md を参照してください。

## 使用フロー

1. `python3 scripts/validate_input.py "<入力文字>" "<軌道>"` → 通過したら続行
2. 入力写真の準備（V1 は写真を直接利用可能）
3. `python3 scripts/render.py --config examples/<case>/config.yaml` → 1200×1600 PNG を出力
4. 視覚品質ゲート：文字を一字ずつ照合（文字化けゼロ）、永続マイクロテキスト "TRACE・ART" が在位、穴あき縁/アート枠が在位
5. 新しいケースは `examples/<case>/input.jpg + prompt.txt + config.yaml + output.jpg` のペアで保存（examples ディレクトリがそのまま評価セットになります）

## 絶対制約（違反はやり直し）

- 生成物にはアート化枠/穴あき縁/マイクロテキストを必ず残すこと。どの設定でも迂回不可（法的防波堤）
- テキストのレンダリング失敗（豆腐ブロック/文字欠落）はエラーを返すこと。欠けた完成品は出力禁止
- 印影テクスチャ（回転/ズレ/墨のにじみ）は必ず有効にすること。完全な幾何学印面は出力禁止
- 実物の印鑑の模造は生成しないこと。生成物は寸法とディテールで本物と明確に区別できること

## 反復規律

- 各リリースにはユーザーに見える変化（新テンプレート/新テクスチャ/新ケース）を必ず含める
- 新テンプレートはまず考証（文化的原型/寸法/読み順/配色）を書いてから render.py に入れること。各テンプレートは最低1つの examples/ ケースに対応し、リグレッションを通過させる
